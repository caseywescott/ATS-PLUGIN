# Modern ATSH Phase 0 Compatibility Baseline

**Scope:** research lockdown and classic compatibility checks before the modern
ATSH engine changes the model or tracker behavior.

## Source-Review Decisions

- **Classic ATS stays available and remains the default.** Phase 0 treats the
  current ATSA/Qatsh-compatible pipeline as `classic_ats` with the
  `classic_recursive_frequency_smr` tracker. Modern and experimental analysis
  modes must be explicit opt-ins until they pass the acceptance criteria in
  [MODERN_ATSH_PRD.md](./MODERN_ATSH_PRD.md).
- **The modern assignment tracker is optional until measured.** Linear
  assignment is promising for close or crossing partials, but Phase 0 keeps the
  classic recursive tracker as the reference behavior.
- **Transient preservation comes before full transient modeling.** Early work
  should detect/protect attack windows and avoid smearing before adding a full
  sines-plus-transients-plus-noise lane.
- **Orphan residual energy must be retained.** Residual critical-band energy
  without an active partial target is part of the future model, not disposable
  analysis error.

## Fixture Manifest

The canonical Phase 0 manifest is
[tests/fixtures/ats_compat_manifest.json](../tests/fixtures/ats_compat_manifest.json).
It records seven required categories:

| Close/crossing partials | `crossing_partials_pair` | Generated by repository tooling; redistributed under the project license. |
| Plucked/percussive | `plucked_decay_karplus_like` | Generated by repository tooling; redistributed under the project license. |
| Noisy voice/flute | `breathy_noisy_flute_like` | Generated by repository tooling; redistributed under the project license. |
| Dense polyphony | `dense_polyphony_chord` | Generated by repository tooling; redistributed under the project license. |
| Percussive hit | `broadband_percussive_hit` | Generated by repository tooling; redistributed under the project license. |

Future recorded fixtures may replace or supplement generated fixtures only if
their manifest entry names the source URL or recording session, copyright
holder, and redistribution-compatible license.

Expected metrics are:

- `reconstruction_error`: input/reference versus resynthesis RMS or peak error.
- `spectral_distance`: framewise log-magnitude or spectral distance in dB.
- `track_continuity`: births, deaths, gaps, and identity continuity events.
- `transient_flux`: attack sharpness preservation using spectral-flux or
  attack-energy ratios.
- `residual_energy_preservation`: critical-band residual energy retained after
  sinusoidal extraction.

The `ats_fixture_manifest` CTest validates that every category, metric,
provenance field, and license field is present before later fixture audio is
added.

## Classic Compatibility Baseline

Phase 0 does not introduce a modern analyzer path. The baseline is the current
ATSA/Qatsh-compatible route:

- CLI: `tools/ats_offline.c`
- Analysis mode: `classic_ats`
- Tracker mode: `classic_recursive_frequency_smr`
- Default ATS file type: `ATSA_TYPE` (`4`, amplitude/frequency/phase/noise)
- Reference round-trip tolerance: `ats_roundtrip` maximum sample difference
  must remain `<= 1e-5`.
- Golden smoke tolerance: `golden_offline` must produce non-silent output with
  more than 1000 frames.
- Metadata reproducibility: `classic_compat_baseline` runs `ats_offline`
  without a modern-mode flag, requests metadata, and verifies source hash,
  sample rate, frame counts, computed analysis parameters, model partial/frame
  counts, analysis mode, and tracker mode.

The `--metadata <analysis.json>` option on `ats_offline` is intentionally small
and compatibility-focused. It serializes enough about a classic run to recreate
the same analysis request: source hash, input dimensions, analysis mode,
tracker mode, full `ANARGS` defaults/overrides, computed hop/FFT/frame fields,
and model summary fields.
