# Modern ATSH Acceptance Gates

Phase 7 turns the PRD section 7 quality goals into a deterministic acceptance
harness. The harness lives in `src/core/AtsModernAcceptance.h` / `.cpp` and is
covered by a tiered set of CTests.

## Synthetic fixture gates (always deterministic, always run in CI)

`ats_modern_acceptance` runs entirely in-process with synthetic models and
deterministic generated source-audio fixtures:

- Classic render parity — normalized RMS error and compact spectral distance.
- Modern tracker vs. classic tracker on crossing/close-partial and sustained fixtures.
- Modern assignment cost includes phase-continuity diagnostics when sample-rate
  and hop-size context are available.
- Continuity metrics treat short sleeps that are later backfilled by `gap_fill`
  lifecycle events as repaired continuity, not track breaks.
- Short dropout gap-fill interpolates phase on the wrapped shortest path so
  repaired frames do not jump across the `pi`/`-pi` boundary.
- Transient marker/buffer preservation, attack sharpness, and click-step limits.
- Partial plus orphan residual energy preservation.
- Deterministic morph recipe recall and fixed-seed morph renders.
- Modern synthesis real-time-safety flags, finite sample output, and CPU budget.
- Direct Modern ATS source analysis of a two-tone audio fixture, including
  sustained 512 Hz / 768 Hz tracks and finite audible render output.
- Direct Modern ATS source analysis stores oscillator-start phases, not raw FFT
  bin phases, so phase-enabled renders seed partial births consistently.

`ats_modern_acceptance_external_gates` tests the external fixture gate evaluation
logic (Phase 7 addition) using synthetic data — no audio assets needed.
`ats_external_acceptance_driver_contract` also verifies the Python real-audio
driver fails loudly when an enabled external run has missing assets or produces
zero gate checks.

Each gate emits a stable id, observed value, threshold, pass/fail state, and a
short detail string. Callers can keep the default thresholds or supply a stricter
fixture-specific threshold struct.

### Synthetic fixture status

| Fixture | Coverage |
| --- | --- |
| Classic parity sine | normalized RMS and spectral distance stay at zero for identical renders |
| Crossing partials | modern slope-aware assignment has fewer identity errors than classic nearest matching |
| Sustained tone | modern continuity and identity match classic behavior, including phase-wrapped gap-filled short dropouts |
| Protected attack | transient marker and buffer increase attack sharpness while staying below the click-step guardrail |
| Morph recall | recipe JSON and fixed-seed rendered output are deterministic |
| Modern synth | render plan reports caller-owned buffers, no allocation/locks/I/O/analysis, finite samples, and bounded CPU |
| Direct source analysis | `runModernAtsAnalysis` tracks generated two-tone audio, preserves off-bin oscillator phase, and renders a finite non-silent model |

## External real-audio gates (optional, gated by ATS_ENABLE_EXTERNAL_FIXTURES)

Phase 7 adds a second tier for side-by-side comparison with original ATSA/Qatsh
on curated real audio clips. These run only when configured with
`-DATS_ENABLE_EXTERNAL_FIXTURES=ON` and the assets are present.

### Fixture manifest

`tests/fixtures/ats_external_fixture_manifest.json` — schema version 1.

Each entry declares:

| Field | Purpose |
| --- | --- |
| `id` | Stable fixture identifier used in all check IDs |
| `description` | Human-readable summary |
| `category` | Fixture category (matches Phase 0 categories) |
| `input_audio` | Relative path from `tests/fixtures/` to the WAV file |
| `provenance.license` | License text — must not be PENDING before committing audio |
| `expected_sample_rate` / `expected_channels` | Validated by the driver |
| `candidate_analysis_mode` | Candidate mode for the Modern offline tool, default `modern_ats` |
| `enabled_gates` | List of gate names to evaluate |
| `threshold_overrides` | Optional per-fixture overrides for default thresholds |
| `atsa_reference.metadata` | Path to raw `ats_offline --metadata` JSON |
| `atsa_reference.summary_metrics` | Path to stable summary JSON loaded by the C++ gate |

### Gate names

| Name | What is checked |
| --- | --- |
| `classic_parity` | Lower-is-better full-duration normalized RMS error and compact onset spectral distance must not regress beyond the ATSA reference plus fixture tolerance, and must also stay under source-reconstruction ceilings |
| `tracker_continuity` | Smooth active-track continuity regression and identity-discontinuity increase vs. ATSA |
| `residual_energy_preservation` | Rendered residual/noise highpass-ratio delta vs. source audio, falling back to ATSA summaries for older artifacts |
| `transient_preservation` | Rendered attack-sharpness ratio vs. source audio, falling back to ATSA summaries for older artifacts |

### Reference artifacts

ATSA reference metrics are generated by `tests/generate_atsa_references.py`.
This script is NOT part of the normal CI flow — run it manually before audio is
committed. The real-audio acceptance driver then compares those stable ATSA
references against `tools/ats_modern_offline` candidate output.

```sh
python3 tests/generate_atsa_references.py \
  --ats-offline ./build/tools/ats_offline \
  --manifest tests/fixtures/ats_external_fixture_manifest.json \
  --output-dir tests/fixtures/reference
```

Output per fixture:
- `tests/fixtures/reference/<id>_atsa_metadata.json` — raw `ats_offline` metadata
- `tests/fixtures/reference/<id>_summary.json` — stable sorted metrics loaded by the gate

The summary includes both model diagnostics and rendered-audio proxies:
`continuity_score` measures smooth active-to-active track transitions rather
than sparse-track density or terminal lifecycle events, `identity_errors` counts
large frequency jumps within a track, `residual_highpass_ratio` tracks rendered
residual/noise character, and `attack_sharpness` is computed from rendered WAVs.
`normalized_rms_error` is measured across the full fixture duration so long
resonant decays cannot pass based only on onset quality; compact spectral
distance remains onset-focused because it is intended to catch early tonal
coloration and attack smearing.
Reference generation also records non-gating reconstruction attribution fields:
attack-window and tail-window normalized RMS error, low/mid/high spectral
distance, decay-envelope error/energy/correlation/bias, bounded waveform
alignment lag/correlation, and dominant time, spectral, early/middle/late decay,
and early/middle/late timing/phase error buckets. These fields make quality
failures easier to assign to attack capture, sustained partial tracking,
resonant decay-envelope preservation, timing/phase drift, or residual/spectral
shape work without turning every diagnostic into a gate.
Residual and transient preservation compare Modern rendered shape against the
source fixture when available so Classic coloration or under-rendering cannot be
mistaken for better source preservation. Modern offline metadata also emits
lifecycle-break counts separately so track churn remains diagnosable without
distorting the active-to-active continuity score.

The Modern assignment tracker treats large last-active-to-next frequency jumps
as identity breaks even when the short-term slope predictor would otherwise make
the jump cheap. The sustained `external_vowel_phrase` gate therefore requires
zero Modern identity errors against the ATSA reference rather than accepting a
fixture-specific increase.

### Current external fixture status

Four first-party fixtures are committed under `tests/fixtures/audio/`:
plucked_guitar, crotale_hit, vocal_chop, and vowel_phrase. These samples were
created by Casey Wescott for ATS-PLUGIN testing, downmixed/converted to mono
PCM16 where needed, and are permitted for repository tests and redistribution
with the project. The initial real-audio gate enables `classic_parity` for all
four fixtures plus real rendered-audio residual/transient checks. The longer
`external_vowel_phrase` fixture also enables `tracker_continuity` because it has
enough sustained material for the track-continuity estimate to be meaningful.
It also ratchets continuity to no regression and identity continuity to zero
permitted errors so long vocal material cannot pass by jumping one partial
between unrelated harmonics.
`external_plucked_guitar` and `external_crotale_hit` carry fixture-specific
spectral-distance tolerances for onset-heavy material while retaining the
no-RMS-regression check. Classic parity also includes source-quality ceilings
for normalized RMS error and spectral distance, with tighter per-fixture
ratchets on the first-party samples. This keeps future Modern changes from
passing merely because they remain better than a loose ATSA baseline. All four
fixtures use a tightened 0.005 source-referenced residual highpass delta and
the shared 0.95 source-referenced transient-sharpness floor so later
residual/transient render changes cannot silently soften or recolor attacks.
Modern transient source buffers protect 160 ms after each detected onset, with
captured buffers allowed up to 220 ms. This keeps percussive resonant attacks
and their early ringing source-anchored long enough for the modeled
partial/residual tail to take over without early spectral overshoot.

When `ATS_ENABLE_EXTERNAL_FIXTURES=ON`, the Python CTest treats missing audio,
missing reference metrics, unknown gates, and zero emitted gate checks as
failures. This keeps an explicitly enabled real-audio gate from reporting
success while proving nothing. The gate-logic C++ test and driver contract test
always run on synthetic data.

The external driver prints an advisory diagnostic block for each fixture after
the gate checks. It breaks source reconstruction error into attack-vs-tail
normalized RMS, low/mid/high compact spectral distance, residual highpass
source delta, transient sharpness ratio, full-duration decay-envelope error,
decay energy ratio, decay correlation/bias, early/middle/late decay focus,
bounded waveform-alignment lag/correlation/aligned NRMS, and available Modern
model proxies such as orphan residual ratio and transient buffer counts. A
final ranked summary orders fixtures by source normalized RMS error while
showing the dominant decay focus and alignment gain, so the next improvement
target is visible immediately after a run.

## Design principle

**Synthetic fixtures are the CI baseline.** They catch regressions without any
external assets and run deterministically everywhere.

**External fixtures are the stricter real-audio parity gate.** They catch
divergence from original ATSA behavior on actual recorded material. They are
optional so CI remains fully reproducible without committing audio files, but
once enabled they require complete fixture assets and reference metrics.
