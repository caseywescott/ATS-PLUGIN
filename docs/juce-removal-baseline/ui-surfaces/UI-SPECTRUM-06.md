# UI-SPECTRUM-06 — Mode controls and keyboard actions

Status: implemented — parity port complete; see `docs/spectrum-view-parity-spec.md`.

The partial and residual toolbars are generated by `SpectrumChromeLayout` and
painted as renderer commands. Toolbar availability follows the current
selection and mode. The partial toolbar exposes Draw, Solo, Freeze, Prune, and
Tilt; the residual toolbar exposes Draw, Smooth, Copy, Paste, Swap, Redist,
and Tilt.

The spectrum page handles Delete/Backspace, Escape, Home, `0`, Cmd/Ctrl+A,
and residual Cmd/Ctrl editing shortcuts. Key handling is routed through
`SpectrumInteractionModel`; no legacy harmonic-class `'h'` shortcut is used.

Evidence: `src/ui/SpectrumChrome.h`, `src/ui/SpectrumInteractionModel.h`,
`src/ui/VisageEditor.cpp`, `tests/spectrum_chrome_test.cpp`,
`tests/spectrum_dispatch_test.cpp`.
